Dental Macros - installing the portable copy
===========================================

Upgrading from MacroDeck (this program's old name)? Copy these files into
your existing MacroDeck folder, then delete MacroDeck.exe from it. Your
macros, layouts and backups stay where they are.

This is the zip version. There is nothing to install and nothing to download
first - everything Dental Macros needs is in this folder.

Keep the folder together. Beside DentalMacros.exe are three files:

    msvcp140.dll
    vcruntime140.dll
    vcruntime140_1.dll

Those are the Microsoft C++ runtime. Dental Macros will not start without them,
so copy the whole folder rather than picking DentalMacros.exe out of it. (If you
ever see "The code execution cannot proceed because VCRUNTIME140.dll was not
found", that is what happened - copy the folder again, complete.)


1. Put the folder somewhere you can write to
--------------------------------------------
Dental Macros keeps its settings in the same folder as DentalMacros.exe, so it has
to live somewhere your account can write. Good choices:

    C:\Users\<you>\Programs\Dental Macros
    C:\Users\<you>\Documents\Dental Macros
    a USB stick

Do NOT put it in C:\Program Files - Windows will not let it save your macros
there unless you run it as administrator.


2. Run DentalMacros.exe
--------------------
The first time, Windows may show a blue box saying "Windows protected your
PC". That appears for any program it has not seen before, not because
anything is wrong. Click "More info", then "Run anyway".

If instead you get "An Application Control policy has blocked this file",
that is Smart App Control. See the "Before you start" section of README.md
for what your options are.


3. Start it automatically when you sign in
------------------------------------------
Open Settings inside Dental Macros and tick:

    [x] Run Dental Macros when I sign in to Windows
    [x] Start listening as soon as Dental Macros opens
    [x] Start minimised to the notification area

All three together mean it is running and watching your macro pad from the
moment you log in, without a window in your way.

(Copying this folder into the Startup folder does NOT work - Windows only
runs items placed directly in it, and it will not look inside a subfolder.)


4. Set up your macro keyboard
-----------------------------
Plug in the spare keyboard or numpad you want to dedicate to macros, click
"Scan for keyboards", and pick it from the list.

Careful: by default, whichever keyboard you pick will stop typing into your
programs while Dental Macros is listening. Pick the spare one, not the one you
type on.

If you would rather put macros on F13-F24 or the extra keys of the keyboard
you actually type on, you do not have to give up the whole thing. Right-click
the keyboard in the list and untick:

    [ ] Turn off all normal input, not just macro keys

With that unticked, only the keys you bound to a macro stop typing - every
other key on that keyboard carries on as normal.

If you ever get stuck with a keyboard that has gone silent, press
Ctrl+Alt+Shift+M - that stops Dental Macros listening from anywhere in Windows
and hands the keyboard straight back.


Uninstalling
------------
Delete the folder. Dental Macros does not touch anything else, apart from one
registry value if you ticked "Run Dental Macros when I sign in to Windows" -
untick that first, or delete the "Dental Macros" value from:

    HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
